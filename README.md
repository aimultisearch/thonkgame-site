# thonkgame.com

Website of **THONK!**, the whack-a-monster game by LM Tech Studio.
Static site served by GitHub Pages (custom domain in `CNAME`).

- `index.html`: home page (with a playable mini board)
- `privacy.html`: privacy policy (linked from the Google Play listing)
- `assets/`: images exported from the game (webp)
